## 待用户真机验证
### M3 评估
1. 后端设置 `ANTHROPIC_API_KEY` 后完成一个 session：色块从 `…` 变为分数；详情有总结与偏离片段。
2. 用无效 key：3 次后显示 `—`，点“重新评估”回到 `…`。
3. 后端关闭 / 未配置 token 时不出现错误条。
4. 第一次真实评估要看后端日志有无 `API_ERROR`：Anthropic SDK 的请求格式只对照过文档与类型，没有真实调用过。

### M4 设置 / 权限
5. 首次启动弹出一次权限引导，重启后不再弹。
6. 设置页修改黑名单 / 专注时长 / 闲置阈值：后端约 1 秒后收到 PUT，重启后端后仍在；进行中的 session 不受影响，下一个生效。
7. 停掉后端再改设置：出现“未同步”；后端恢复后重启 App 会补推。
8. 保存后端地址与 Token 后不重启就能重新加载任务；Token 出现在钥匙串（service = session）。
9. 设置页打开期间不会反复读钥匙串（无反复弹窗）。
10. 辅助功能 / 通知状态在授权后回到 App 时变绿；“打开系统设置”跳转到正确页面。

### M4 统计
11. 统计页三个范围的数字与今日页一致；趋势线在无评估的日子断开；无分类为灰色。
12. 无 Token / 后端关闭时显示占位文案。

### 打包
13. `mac/scripts/build-app.sh` → 打开 `build/Session.app`：权限引导出现；session 结束收到系统通知；拦截与采集可用。
14. ad-hoc 签名重编译后系统可能重新询问权限（见 `mac/README.md`）。

### 拦截标签页恢复（审查后的改动）
15. 重定向后，session 结束 / 放弃 / 退出 App，标签页回到原网址。
16. 有空白 Safari 标签页时仍能恢复其他标签页。
17. 从未重定向过时，启动 / 结束 session 不触发任何自动化权限弹窗。
18. 强杀 App 后重启：不重复恢复，也不发通知；原页面可通过拦截页上的链接手动返回。
19. 控制台日志里不再出现完整 URL。

## 审查后遗留（有意不修）
- 设置在多设备间后写覆盖（客户端总是发送全部四个字段）；当前仅一台 Mac。
- 同步遇到后端不认识的分类 / 条目 ID 时存为无分类（M2 计划已接受）。
- 服务端不校验 `actualSeconds` 与起止时间一致、span 是否在 session 内（单用户可接受）。
- `activity_spans.id` 是全局主键，跨用户碰撞时静默丢弃（多用户阶段再改为复合键）。
- 同步服务在重新配置 API 后可能短暂并存两个实例（服务端幂等，无害）。
- 其余：Docker 镜像未构建验证；Docker 以 root 运行；seed 的 token 走命令行参数；并发创建同名条目可能重复；“额度 90% 提醒”需要重置时间。
